# Уютный планер — Telegram Mini App

Личный планер, трекер привычек, финансы и мягкая игровая механика в одном файле `index.html` (без сборки и бэкенда).

## Игровая механика
- **Профиль** — аватар, имя, уровень, звание (Чистый лист → Первые заметки → … → Мудрый котик), шкала опыта.
- **Опыт и монетки** — задача: 10 / 15 / 25 XP по сложности; привычка: 6 XP + бонус за серию (до +14).
- **Котобосс недели** — каждый понедельник новый котик (Кот Прокрастинатор, Кот Лени, Кот-Скроллер…).
  Его упрямство подстраивается под твою активность за прошлые две недели, весь опыт за неделю его укрощает.
  Укрощённый котик мурлычет 😽 и даёт награду: +120 XP и +60 монеток.
- **Задания дня** — 3 случайных задания каждый день («Ранняя пташка», «Разгреби просроченное»…), награду надо забрать.
- **Наклейки** — коллекция достижений за задачи, серии, боссов, уровни и квесты.
- **Награды для себя** — свои реальные награды («Серия сериала — 40 монеток»), покупаются за заработанные монетки.
- Эффекты: всплывающий опыт, удар по боссу, конфетти, окно нового уровня, новые наклейки, вибрация в Telegram.

Опыт считается из данных: если снять галочку, награда тоже отменяется, так что накрутить нельзя.

## Разделы
Мой день (профиль, котобосс, задания, дела на сегодня) · Задачи · Привычки · Цели · Деньги · Профиль (обо мне, награды, наклейки, итоги-статистика).

Данные хранятся в **Telegram CloudStorage** (синхронизация между устройствами) + localStorage как кэш.

## Запуск
1. **Захостить `index.html` по HTTPS** — GitHub Pages, Netlify, Vercel или Cloudflare Pages.
2. **Создать бота** в @BotFather → `/newbot`.
3. **Подключить мини-апп**:
   - без кода: @BotFather → `/mybots` → бот → *Bot Settings → Menu Button* → вставить URL;
   - или через `bot.py`:
     ```
     pip install "aiogram>=3"
     BOT_TOKEN=... WEBAPP_URL=https://... python bot.py
     ```

Локально можно открыть через любой статический сервер. Сбросить весь прогресс можно в «Профиль → Обо мне → Очистить всё».
